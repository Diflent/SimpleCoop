# SimpleCoop — кооператив для Ostranauts

Мод на [BepInEx](https://github.com/BepInEx/BepInEx) для **Ostranauts**: до **4 игроков** в одном мире.
Один игрок — **хост**: он запускает своё сохранение, и весь мир считается у него. Остальные — **клиенты**: подключаются к хосту по IP, загружаются в его мир и управляют каждый своим членом экипажа.

> Статус: ранняя разработка (v0.0.1). Основной цикл «подключиться → загрузиться в мир хоста → играть вместе» работает. Часть механик игры пока не синхронизируется, см. «Известные ограничения».

---

## Что уже работает

### Подключение
- **Прямое подключение по IP:порт**, без лобби и списка серверов. Рассчитано на Radmin VPN, Hamachi или локальную сеть.
- **Хост запускается только из загруженной игры**: из главного меню сервер не стартует.
- **Проверка совместимости при подключении**: версия протокола мода и версия игры. При несовпадении клиент отключается с понятной причиной.
- **Клиент загружается в мир хоста автоматически.** Хост ставит игру на паузу, сохраняет мир и передаёт сохранение клиенту, а клиент сам его загружает. Подключаться можно прямо из главного меню. Если подключаются сразу несколько игроков, они обслуживаются по очереди.
- **Если хост выходит в меню**, сервер останавливается.

### Персонажи игроков
- **Каждый клиент получает своего члена экипажа.** Это свободный нанятый член экипажа хоста, а если свободных нет, хост автоматически нанимает нового.
- **Переподключение возвращает того же персонажа**: игрок узнаётся по ключу из конфига.
- **Персонаж клиента не берёт автозадачи**: ИИ хоста не раздаёт ему работу. Когда клиент отключается, персонаж возвращается под управление ИИ.
- **Каждый управляет только своим персонажем.** Клиент не может приказывать чужим, хост не может приказывать персонажам клиентов.

### Действия и мир
- **Перемещение.** Приказ «идти» клиента выполняется на хосте. Позиции персонажей приходят клиентам примерно 7 раз в секунду, с плавной интерполяцией и анимацией ходьбы.
- **Взаимодействия.** Клик по объекту (выключатели, двери, терминалы и т.п.) выполняется на хосте, а результат применяется у всех игроков.
- **Предметы через действия**: подобрать, надеть, выбросить, съесть или выпить, взять из контейнера.
- **Инвентарь**: перетаскивание предметов в окне инвентаря (между слотами, контейнерами и полом) синхронизируется в обе стороны.

### Время
- **Пауза** общая: её может поставить или снять любой игрок.
- **Скорость** (ускорение и замедление) управляется хостом, клиенты её повторяют.
- **Игровые часы клиента** автоматически подстраиваются под часы хоста.

## Установка

1. Установите **BepInEx 5** для Ostranauts (например, `BepInExPack_Ostranauts` с Thunderstore).
2. Скопируйте в `<папка игры>\BepInEx\plugins\SimpleCoop\` два файла:
   - `SimpleCoop.dll`
   - `LiteNetLib.dll`
3. Запустите игру один раз: появится конфиг `BepInEx\config\com.Diflent.ostranauts.SimpleCoop.cfg`.

Мод должен быть **одной версии у всех игроков**, иначе хост отключит клиента.

## Как играть

**Хост:**
1. Загрузите сохранение.
2. Нажмите **F5**: сервер запущен на порту `7777` (UDP).
3. Сообщите клиентам свой IP из Radmin VPN или Hamachi.

**Клиент:**
1. В конфиге укажите `HostIP` (IP хоста).
2. В главном меню или в игре нажмите **F6**.
3. Дождитесь загрузки мира хоста: ваш персонаж будет выделен, камера наведена на него.

### Клавиши

| Клавиша | Действие |
|---|---|
| **F5** | Запустить сервер (хост, только из игры) |
| **F6** | Подключиться к хосту (клиент) |
| **F7** | Отключиться / остановить сервер |
| **F8** | Тестовое сообщение в чат |
| **F10** | Показать / скрыть оверлей мода |
| **F11** | Подробный лог синхронизации в оверлее |

### Настройки (`com.Diflent.ostranauts.SimpleCoop.cfg`)

| Секция | Параметр | По умолчанию | Описание |
|---|---|---|---|
| Network | `HostIP` | `26.0.0.1` | IP хоста (для клиента) |
| Network | `HostPort` | `7777` | Порт сервера |
| Network | `ClientPort` | `7779` | Локальный порт клиента |
| Network | `ConnectionKey` | `SimpleCoopKey` | Ключ подключения, должен совпадать у всех |
| Player | `Name` | имя пользователя Windows | Ваше имя в логе хоста |
| Player | `Key` | создаётся автоматически | По нему хост возвращает вам того же персонажа |
| Host | `AutoCreateCrew` | `true` | Нанимать нового члена экипажа, если свободных нет |
| Host | `AssignedCrew` | — | Служебное: закрепление персонажей за игроками |

## Известные ограничения

- **Новые предметы** (лут, крафт, разделение стопок) и **удаление предметов** (корзина, полное потребление) пока не синхронизируются. У клиента такие предметы могут отсутствовать: в логе это видно как `missing CO`.
- **Случайные исходы действий** (`MathUtils.Rand`) могут выпасть у клиента иначе, чем у хоста.
- **NPC на клиенте** сами выбирают задачи и ходят, иногда «дёргаясь» между своей позицией и позицией с хоста.
- **Общая компания.** У клиента деньги, компания и PDA — общие с хостом.
- **Перемотка времени** (окно сна / FFWD) доступна только хосту.
- **Установленное оборудование** (монтаж и демонтаж) пока не синхронизируется.

## Планы

### Ближайшее
- [ ] **Появление и удаление предметов.** Хост рассылает созданные объекты с тем же `strID` (через `DataHandler.GetCondOwner(..., strIDOld, ...)`) и удалённые (`CondOwner.Destroy`). Сюда же входят стопки и корзина.
- [ ] **Отключить решения ИИ на клиенте.** NPC у клиента не выбирают задачи сами: их поведение целиком приходит с хоста.
- [ ] **Внешность персонажа клиента.** Клиент сам настраивает внешность (и, возможно, имя) своего персонажа, хост применяет и рассылает её.

### Дальше
- [ ] Синхронизация состояний (conds): потребности, ранения, состояние оборудования. Плюс контроль рассинхрона.
- [ ] Монтаж и демонтаж оборудования, постройка.
- [ ] Перемотка времени для всех игроков.
- [ ] Роли и права (капитан / инженер / медик).
- [ ] Отдельные кошельки игроков (сейчас всё общее).
- [ ] Компрессия пакетов, prediction / reconciliation для движения.
- [ ] Проверка одинакового набора модов у всех игроков.

## Для разработчиков

### Архитектура
Хост авторитетен: клиент отправляет только **намерения**, хост их выполняет и рассылает **результат**.

| Файл | Назначение |
|---|---|
| `SimpleCoop.cs` | Плагин BepInEx: конфиг, Harmony, клавиши, главный цикл |
| `NetworkManager.cs` | LiteNetLib: подключение, рукопожатие, разбор пакетов, готовность клиентов |
| `SaveTransfer.cs` | Передача сохранения хоста клиенту и его загрузка |
| `PlayerRegistry.cs` | Назначение персонажей игрокам, проверка «чей персонаж» |
| `OrderSync.cs` | Приказы клиента (идти / действие) → хост |
| `ActionSync.cs` | Результаты взаимодействий (`Interaction.ApplyEffects`) хост → клиенты |
| `ItemSync.cs` | Где лежит предмет (слот / контейнер / пол), в обе стороны |
| `PositionSync.cs` | Позиции персонажей, интерполяция, анимация |
| `TimeSync.cs` | Пауза, скорость, игровые часы |
| `CoLookup.cs` | Поиск объектов по `strID` |
| `ModOverlay.cs`, `GameLog.cs` | Оверлей и лог мода |

Все ссылки на объекты передаются через `CondOwner.strID`. Совпадение ID у всех игроков гарантирует загрузка клиентом сохранения хоста.

### Сборка
Проект — `net472`, ссылается на DLL игры и BepInEx. Путь к игре определяется в `SimpleCoop.csproj` (`OstranautsPath`). Если игра стоит в другом месте, создайте рядом с `.csproj` файл `Directory.Build.props` (он в `.gitignore`):

```xml
<Project>
  <PropertyGroup>
    <OstranautsPath>C:\путь\к\Ostranauts</OstranautsPath>
  </PropertyGroup>
</Project>
```

Собранный `SimpleCoop.dll` кладётся прямо в `BepInEx\plugins\SimpleCoop\` игры.

### Тест на одном компьютере
1. Скопируйте папку игры, например в `E:\OstranautsClient`. Не в `E:\Ostranauts`: этот путь проверяется сборкой первым.
2. В копии удалите строку `single-instance=` из `Ostranauts_Data\boot.config`.
3. В конфиге копии укажите `HostIP = 127.0.0.1`. Если копия сделана после первого запуска мода, очистите `Player.Key`.
4. Хост запускается через Steam, клиент — напрямую через `Ostranauts.exe` в копии.

### Протокол
При любом изменении формата пакетов увеличивайте `NetworkManager.ProtocolVersion`.
